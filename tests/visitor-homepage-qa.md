# T29 — تحقق صفحة الزائر

١٧ تشرين الأول ٢٠٢٦. بدأ الفرع من main عند 0af60c4 بعد سحبه. لا تعديل لـ catalog.js أو profiles.js أو مفاتيح تقدم الطلاب.

## ما تغيّر

- index.html يعرض صفحة عامة عند عدم وجود جلسة طالب صالحة، ويحتفظ بمختار الصفوف والمواد الحالي للطالب المسجل.
- welcome.js يتحقق بالقراءة فقط من الجلسة والمالك والملف وعدم وجود انتقال أو استعادة معلّقة، قبل تحميل ملفات الطلاب. ينتظر PROFILES.ready ويعيد التحقق قبل إظهار المختار. حارس النقر وأحداث التخزين يمنعان استعمال المختار القديم بعد تغيير الجلسة أو حذف الملف بتبويب آخر.
- معاينة الطالب العامة عبر ?welcome=1، وعينة الكسور في الذاكرة فقط، بلا نقاط أو إتقان أو تخزين.
- welcome.css وأيقونات SVG محلية، وخطوط الموقع المحلية، وحركة تراعي إعداد تقليل الحركة. الفقرات بحجم ١٦ بكسل على الأقل والتسميات الأساسية ١٤.
- صورة زيتون الجديدة assets/img/visitor-hero-v1.webp شفافة، ٩٦٠ × ٩٦٠، ١٨٨٢٧٠ بايت. الأصل القديم محفوظ. وصف التوليد في assets/img/visitor-hero-source.md.
- عُدّل sw.js الجذري عمدًا لحفظ ملفات الصفحة والصورة ورفع نسخة الكاش. لا تغيير لحذف كاش المواد أو SUB. مقارنة النسخة في الاختبار تعتمد مرجع Git، دون اسم إصدار ثابت.

## نتائج التحقق

- شُغّل كل ملف tests/*.cjs بعملية Node مستقلة؛ ١١ ملفًا ناجحًا. اختبار visitor-homepage.cjs يتحقق من ٩٠ حالة، تشمل غياب الجلسة وفسادها، وعدم تطابق المالك، وعدم وجود الملف، والانتقال والاستعادة المعلّقين، وفشل تحميل ملفات الطالب، وتبديل الجلسة، وحذف الملف، والعينة وعدم الكتابة، وتغيّر الكاش.
- Edge فعلي مع عرض ٣٦٠ و٣٩٠ و١٣٦٦: ست حالات للزائر، زيارة أولى ثم إغلاق المتصفح وإعادة فتح سياق دائم بلا شبكة. الصورة والأيقونات والخط والعينة تعمل؛ استُعملت لوحة المفاتيح لإحدى القطع. لا تجاوز أفقي ولا أخطاء console أو page errors.
- على ٣٩٠ و١٣٦٦: دخول بملف اصطناعي، عرض المختار والاسم الصحيح، ?welcome=1 بلا تغيير البيانات، اختيار السادس ثم العلوم، والعودة عبر ?change=1. بقي تقدم الرياضيات كما كان. اختُبر حذف ملف الطالب وحده ثم الخروج من تبويب آخر، فاختفى المختار القديم.
- سبع حالات جلسة غير صالحة أو معلّقة في المتصفح؛ بقيت جميع مفاتيح التخزين كما كانت. الزائر الجديد يبقى بلا مفاتيح، ولا تُحمّل له ملفات PROFILES.
- ٣٦٠ و١٣٦٦ مع الحركة العادية: ظهور الأقسام عند التمرير، وحركة الصورة، وزر الدخول المرئي بالرأس، وفقرات لا تقل عن ١٦ بكسل. فُحص تقليل الحركة في حالات الاختبار الأساسية.
- دون JavaScript تبقى الصفحة العامة ونصوصها وروابط الدخول ظاهرة، مع تنبيه أن عينة التلوين تحتاج تفعيله.
- اتصال محاكى في متصفح بانتظار ٣٥٠ مللي ثانية وسرعة تنزيل ٦٠ كيلوبايت/ثانية: أمكن حل العينة دون تخزين أو أخطاء صفحة؛ نحو ٣٫٨ ثوانٍ في هذا الاختبار المحلي. هذا لا يقيس اكتمال تنزيل كل محتوى المواد أو أداء شبكات الطلاب.
- بقي تحويل رابط الجذر القديم #/home إلى g8/math/#/home صحيحًا عند وجود جلسة طالب صالحة.

## إعادة الفحص يدويًا

شغّل خادم ملفات محليًا، وافتح الموقع في سياق متصفح تجريبي مستقل. لا تستخدم ملفات عبود وميرا للاختبار. جرّب القطع مرة بإجابة خاطئة، ثم اختر قطعتين وتحقّق، ثم أعد البداية. قارن localStorage قبل العينة وبعدها. انتظر تفعيل عامل الخدمة، أغلق المتصفح، ثم أعد فتحه بلا شبكة وكرر العينة. بعدها استخدم ملفًا اصطناعيًا لاختبار المختار و?change=1 و?welcome=1، وغيّر الجلسة من تبويب ثانٍ.

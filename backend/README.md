# خادم بستان التعلّم

مشروع Laravel مستقل داخل المجلد الفرعي backend من المستودع نفسه. الصفحة الحالية تؤكد تشغيل الإطار فقط؛ لا تحتوي تسجيل دخول أو حفظ محتوى أو مزامنة مفعّلة. واجهة الإدارة في طلب المراجعة ٢٧ منفصلة، ولا تُنسخ داخل public ولا تُربط آليًا بهذه التهيئة.

## التشغيل المحلي

المتطلبات: PHP ٨٫٢ أو أحدث وComposer، مع امتدادات Laravel وpdo_sqlite للتجربة المحلية. استُخدم Laravel ١٢ ليتوافق مع PHP ٨٫٢ المتاح على الجهاز. راجع [سياسة الإصدارات الرسمية](https://laravel.com/docs/12.x/releases) عند اختيار إصدار خادم الإنتاج؛ Laravel ١٣ يحتاج PHP ٨٫٣ على الأقل.

من داخل backend:

```powershell
composer install
Copy-Item .env.example .env
php artisan key:generate
New-Item -ItemType File database/database.sqlite
php artisan migrate
php artisan serve --host=127.0.0.1 --port=8000
```

نفّذ نسخ البيئة وإنشاء قاعدة SQLite فقط في التثبيت الأول إذا لم يكونا موجودين. لا تستبدل .env أو قاعدة موجودة. هذه التهيئة المحلية أنشأتهما مسبقًا؛ يكفي أمر serve للتشغيل الحالي. افتح http://127.0.0.1:8000 . لا تحتاج صفحة التهيئة إلى npm أو Vite أو اتصال بخدمات خارجية. composer install يحتاج إنترنت مرة لتنزيل الحزم، وبعده يعمل الخادم محليًا دون اتصال.

SQLite للتطوير فقط، ويمكن اختيار MySQL عبر إعدادات DB_* في .env وتنفيذ الترحيلات على قاعدة التطوير المختارة. لا توجد بيانات طلاب منسوخة ولا حساب افتراضي مزروع. لا تستعمل migrate:fresh على قاعدة فيها بيانات تريد الاحتفاظ بها.

## الاختبار

``powershell
php artisan test
composer validate --strict
composer audit
```

الاختبارات تستخدم SQLite في الذاكرة؛ لا تفتح قاعدة التطوير. رابط /up يفحص إقلاع Laravel، ولا يثبت اتصال قاعدة البيانات أو جاهزية المزامنة.

## الاستضافة والربط

- GitHub Pages يشغّل الموقع الثابت فقط ولا يشغّل PHP. ارفع Laravel لاحقًا إلى استضافة PHP، واجعل جذر الويب backend/public فقط. لا تجعل جذر المستودع أو backend جذر الويب للخادم.
- .env والمفاتيح وقواعد SQLite وvendor وملفات السجلات مستثناة من Git. composer.lock محفوظ لإعادة تثبيت الحزم نفسها. في الإنتاج اضبط APP_ENV=production وAPP_DEBUG=false وAPP_URL الصحيح وHTTPS وإعدادات قاعدة البيانات.
- لا تُضمّن أسرارًا في واجهة الإدارة أو JSON العام. يلزم تسجيل الدخول والصلاحيات والتحقق من البيانات والصور في الخادم قبل إتاحة أي كتابة.
- قبل تقديم لوحة خاصة عبر Laravel، طبّق دليل LARAVEL-HANDOFF.md من واجهة الإدارة بشأن إلغاء كاش المعاينة العامة للصفحات الخاصة. لا تمس كاش مواد الطلاب أو مفاتيح تقدمهم.
- يُصمَّم نقل التقدّم الحالي وحل التعارضات منفصلًا؛ لم تُحمّل profiles.js أو تُغيَّر مفاتيحها هنا. تبقى قرارات الكتاب واستعادة النسخة الاحتياطية السابقة كما هي.

الحسابات والحفظ والنشر ورفع الصور وواجهات API ليست منفّذة في هذه الدفعة؛ المشروع جاهز لبدء ربطها دون تغيير الموقع الثابت.

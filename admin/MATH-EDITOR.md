# محرّر المعادلات والكسور

مكوّن محلي لمصمم الاختبارات؛ لا يحسب الإجابة، ولا يدّعي مطابقة سؤال للكتاب تلقائيًا، ولا يستخدم مكتبات أو خطوطًا خارجية. الصيغة الرياضية جزء اختياري من السؤال، مستقل عن نصه وعن مفتاح الإجابة.

تُعرض المتغيرات العربية رموزًا مستقلة، فلا يلتحم س وص كحروف كلمة. يبقى ترتيب أجزاء التعبير وفق ترتيب إدخالها، مع عزل الرموز عن اتجاه النص المحيط. يحافظ العرض على جـ والأعداد متعددة الخانات كوحدات كاملة. تستخدم حقول التحرير علامات عرض غير مطبوعة لفصل الحروف وتثبيت الاتجاه؛ لا تُحفظ هذه العلامات في بيانات المعادلة، ويزيلها النسخ والقص. تُراعى مواقع المؤشر عند الإدراج والحذف.

## الربط

حمّل `math-editor.css` و`math-editor.js` قبل تشغيل مصمم الاختبارات. الواجهة العامة:

```js
const binding = MATH_EDITOR.mount(container, question.math, value => {
  if (value.tokens.length) question.math = value;
  else delete question.math;
});
const checked = MATH_EDITOR.validate(question.math); // {ok, errors, value}
const html = MATH_EDITOR.render(checked.value);
binding.destroy();
```

لا يستدعي `mount` دالة التغيير عند الفتح الأول. يستبدل مستمعي النسخة السابقة عند فتح المكوّن مجددًا في الحاوية نفسها. عند إزالة الحاوية، يستدعي المالك `destroy()` لتحرير المستمعين. لا يُقرأ أو يُكتب التخزين المحلي أو أي مسار API.

## بنية البيانات

```json
{
  "version": 1,
  "tokens": [
    {"kind": "text", "value": "س + "},
    {"kind": "fraction", "numerator": "١", "denominator": "٢"},
    {"kind": "text", "value": " = "},
    {"kind": "root", "value": "٩", "index": ""},
    {"kind": "text", "value": " + "},
    {"kind": "power", "base": "ص", "exponent": "٢"}
  ]
}
```

هذا مثال تنسيق فقط، وليس مسألة من الكتاب أو مساواة صحيحة معتمدة.

الأنواع المدعومة: نص رياضي، وكسر رأسي، وجذر مع دليل اختياري، وقوة بأس مرتفع. لا تدعم هذه النسخة صيغًا متداخلة داخل حقول الأجزاء. تُعرض أجزاء الصيغة بترتيب المصفوفة من اليسار إلى اليمين، مع عزل اتجاهها عن الفقرة العربية؛ هذا يتسق مع `.mx` في رياضيات الصف الثامن. الكسر يتبع البسط فوق خط والمقام تحته، مثل `.frac` في `g8/math/typography.css`.

## التحقق والحفظ

الحد الأقصى ٤٠ جزءًا، و٢٠٠ حرف لحقل النص، و١٢٠ حرفًا لكل حقل آخر. دليل الجذر اختياري. الأنواع والإصدار وحدود الحقول إلزامية في جميع الأوضاع.

`validate(value)` يرفض الأجزاء المطلوبة الفارغة والصيغة الخالية، ويعيد نسخة بيانات بأرقام هندية عند النجاح. يستعمل مصمم الاختبارات هذا الوضع قبل معاينة الطالب.

`validate(value, {allowIncomplete:true})` يسمح بالحقول الفارغة أثناء حفظ المسودة أو استيرادها، ويظل يرفض الأنواع أو الحدود غير الصالحة. يحذف المالك خاصية `question.math` عندما يحذف المستخدم آخر جزء، حتى تبقى الصيغة اختيارية.

المقام العددي صفر مرفوض في الوضعين، بما يشمل الأرقام الهندية والفارسية والصفر العشري مثل `٠٫٠` و`−٠,٠٠`. المقام الرمزي مثل `س` مسموح. هذا تحقق من إدخال الصفر الصريح، وليس تبسيطًا جبريًا لعبارات مثل `س − س`.

`render` يعيد HTML مهروبًا، ولا يحتاج إلى `document`. النص المتاح لقارئ الشاشة يصف الكسر والجذر والقوة. النصوص المدخلة لا تتحول إلى HTML أو شيفرة. جميع الأرقام الظاهرة والمحفوظة في النسخة المطَبّعة هندية؛ لا تُغيَّر أسماء مفاتيح JSON أو رقم إصدار البنية.

## التسليم إلى Laravel

يمكن حفظ `question.math` كحقل JSON بعد التحقق من البنية في الخادم أيضًا. التحقق الموجود في المتصفح لا يغني عن تحقق Laravel أو صلاحيات المشرف. لا تُنشر المسودة، ولا تُحفظ في قاعدة بيانات من هذا المكوّن.

# منشئ المحتوى — تسليم الواجهة

من المسار `admin/#content-builder` يمكن إنشاء وحدة ودرس ومغامرة ومختبر، وتعديلها ومعاينتها وتصدير حزمة JSON واستيرادها. المسودة في ذاكرة الصفحة؛ التنقل داخل اللوحة يحتفظ بها، وتحديث الصفحة يفقدها. لا تخزين لتقدم الطلاب ولا اتصالات API.

## التأليف والمعاينة

- الوحدة: أهداف مستقلة، مرجع كتاب وصفحة، غلاف اختياري، قائمة الدروس المرتبطة مرتبة بحقل الترتيب.
- الدرس: خطوات قابلة للإضافة والحذف والترتيب، نص وصورة محلية وصيغ رياضية في الرياضيات، ثم سؤال بأربعة خيارات مع تفسير الإجابة.
- المغامرة: مسار مراحل بأسئلة وتغذية راجعة؛ يُفتح الانتقال بعد الإجابة الصحيحة، وتتاح إعادة التجربة.
- المختبر: اختيار أجزاء متساوية لتكوين كسر، أو تحديد نقطة على خط أعداد، أو مشاهدات متتابعة يعدها المعلم. المشاهدات ليست محاكاة علمية تلقائية.

يمكن حفظ الحقول غير المكتملة، وفحص اكتمال الحزمة قبل المراجعة. نجاح الفحص لا يؤكد مطابقة الكتاب؛ المراجع البشري يتحقق من المحتوى والمصطلحات والطريقة. تبدأ الحقول فارغة ولا توجد دروس يُدّعى اعتمادها.

## عقد البيانات

واجهة `CONTENT_BUILDER.validateBundle(raw,{allowIncomplete:false})` تعيد `{ok,errors,value,bundle}`. تكون value نسخة مستقلة تقتصر على الحقول المعتمدة، أو null عند الخطأ. mount(container) يعيد destroy(). تستخدم المعاينة `CONTENT_PREVIEW.mount(container,item,{items,onViewChild})` مع destroy().

الحزمة `{version:'bustan-content-draft-v1',items:[]}` حتى ١٠٠ عنصر وحجم ١٢ ميغابايت. المشتركات: id وtype وgrade (٦ أو ٨) وsubject وterm وtitle وdescription وorder وreference:{book,page} وunitId وlessonId. الأرقام البنيوية في JSON أعداد؛ الأرقام المعروضة في الواجهة هندية. المعرّفات ثابتة وفريدة ضمن الحزمة بما فيها الخطوات والمراحل.

- unit: objectives وصورة image اختيارية؛ unitId وlessonId فارغان.
- lesson: unitId وsteps:[{id,title,body,image?,math?}] وcheck:{prompt,options:[أربعة نصوص],answer:فهرس يبدأ بصفر,feedback}؛ lessonId فارغ.
- adventure: lessonId وtemplate:'path' وstages:[{id,prompt,options,answer,feedback}]؛ unitId فارغ وتُشتق الوحدة من الدرس.
- lab: lessonId وtemplate وconfig؛ fraction:{parts,selected} أو number-line:{min,max,point} أو observe:{question,observations}. القالبان الرياضيان لمادة الرياضيات فقط.

يجب أن تكون الروابط ضمن الصف والمادة والفصل نفسها. تُرفض المراجع المفقودة حتى في الحزمة الجزئية، ويُسمح بالربط null أثناء التأليف فقط. حذف عنصر له أبناء ممنوع حتى تغيير ارتباطهم. يوجد تراجع عن آخر حذف.

الصيغ تستخدم عقد MATH-EDITOR.md. الصور تستخدم `QUIZ_BUILDER.images.prepare(file)` و`images.validate(image,allowIncomplete)` المشتركتين مع مصمم الاختبارات: PNG/JPEG/WebP بحد إدخال ٨ ميغابايت، وتجهيز محلي بحد ١٦٠٠ بكسل للضلع الأطول و٥٠٠ كيلوبايت. الصورة {dataUrl,mime,width,height,alt} مضمنة في JSON؛ الوصف البديل مطلوب للفحص الكامل. عند الاستيراد تتحقق الأبعاد بفك الصورة فعليًا قبل استبدال المسودة.

## ربط Laravel

أضف الحفظ والمصادقة والصلاحيات والمراجعة والنشر والإصدارات على الخادم. أعِد التحقق من كامل المدخلات والروابط والصور في الخادم؛ تحقق JavaScript لتحسين الاستخدام فقط. عالج رفع الصور كوسائط مستقلة عند تحديد عقد API النهائي، ولا تنشر ملف JSON دون مراجعة. لا تضع مفاتيح الإجابة أو محتوى الطلاب الخاص في كاش المعاينة العامة. راجع LARAVEL-HANDOFF.md قبل تحويل HTML إلى Blade.

# الصفّ الثالث — الفصل الأوّل

بنية الصفّ السادس (core.js) بتكبير الخطّ وأهداف اللمس لأعمار 8–9: «ابدأ الدرس» ← خطوات بسؤال سريع ← «تدرّب» بزرّ «تحقّق» ← «أجرّب» (مختبر) ← اختبار الوحدة، مع اختبار تحديد مستوى اختياريّ (`#/place`)، والتقرير، والإنجازات، والمغامرات.

- `shared/core.js` نسخة من محرّك الصفّ السادس؛ تسجيل الإجابات عبر `logAnswer` ← `BUSTAN_REPORT.record` (لا توجد دالّة `report()` عامّة).
- `shared/g3.js` العارض، `shared/g3.css` التكبير.
- `<subject>/content.js` المحتوى (`window.G3`)، و`<subject>.js` المختبرات (`window.G3X`).
- الصوت: لم يُسجَّل بعد. النصوص في `AUDIO.md` لصوت «نورس» (الفصحى البيضاء) بلا موسيقى.
- السعر: 5 شواكل للمادّة / 30 يومًا مثل الصفّين الأوّل والثاني.

# أدلة المراجعة

كل الأدلة تخص `be3f9dd97cd992e1c4ebb8040984a418584811e8`، بتاريخ ١٦ تشرين الأول ٢٠٢٦. الأدوات تقرأ المصدر وتجري محاكاة داخل الذاكرة، ولا تتصل بمتصفح الطلاب أو تكتب إلى مفاتيحه. الملفات هنا أدوات مراجعة وليست إصلاحات للموقع.

- `storage-cache-check.cjs` و`storage-cache-result.json`: فشل حفظ النسخة أثناء التبديل، وسياقا مخزن مشترك، واستعادة جزئية، ورسالة تنزيل بعد فشل كل الملفات. سياق التبويب القديم ينفذ كتابة مماثلة لحفظ التطبيق؛ ليس تشغيل متصفحين فعليين.
- `runtime-check.cjs` و`runtime-result.json`: بناء ملفات JavaScript المتتبعة، ومسح محارف الإيموجي النصية، وتشغيل تقرير علوم الثامن، ودوال نتيجة الاختبار وإعادة الأخطاء، واستراتيجية الشبكة في عامل خدمة الجذر، وعينة جرد تقدير أحجام الصوت. يكشف الاختبار دوال خاصة في نسخة المصدر داخل VM فقط؛ لا يغير الملف الأصلي. لا يمثل DOM البديل محرك عرض أو console المتصفح.
- `science-check.cjs` و`science-result.txt`: عينات مولدات العلوم، ومسارات الدارة، وحركة القوى في إطارين متتاليين. مقارنة صور الكتاب أجريت في دور معلّم العلوم، وليست من وظيفة هذا البرنامج.
- `inventory-check.cjs` و`inventory.json`: أحجام الملفات، وقوائم التثبيت، وإحالات الصوت وصور الإنجليزية وروابط HTML المحلية الحرفية. تشغيل هذا الملف يعيد كتابة ملف الجرد هنا فقط. حقل `emoji` يسجل مطابقة `Extended_Pictographic` الاستكشافية بما فيها الأسهم، ولا يعني أن كل تطابق إيموجي؛ المسح الأضيق موجود في `runtime-result.json`.

التشغيل من جذر المستودع باستخدام Node المحلي:

```powershell
node reviews/evidence/storage-cache-check.cjs
node reviews/evidence/runtime-check.cjs
node reviews/evidence/science-check.cjs
node reviews/evidence/inventory-check.cjs
```

الملفات الناتجة هي سجلات تشغيل المراجعة، ولا تثبت خلو الموقع كله من أخطاء أو مطابقة جميع صفحات المنهاج. حدود المقابلة وفحص المتصفح والاستماع موثقة في التقارير ذات الصلة.

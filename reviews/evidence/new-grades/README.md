# أدلة المراجعة وإعادة الفحص

خط الأساس: `199bca542e07cdcb760a5c9c8481ae26612ad49f`، بتاريخ ١ تشرين الثاني ٢٠٢٦.

- `browser.json`: الجولة المكتملة للمواد الست عشرة، أحجام العرض، أخطاء الصفحة والـconsole، الصور المفقودة دون اتصال، وحالة عامل الخدمة.
- `weak-network.json`: عينة علوم السابع تحت تقييد الشبكة؛ الزمن يشمل خمول الشبكة والخطوط، وليس مؤشر تفاعل معياريًا.
- `g7-question.json`: سؤال المجموعات الفعلي بخياره الفارغ وترقيم الصفحة الداخلي الظاهر.
- `content-structure.json`: الجرد البنيوي لكل مادة؛ أسئلة الثالث تُركب بطريقة مختلفة، لذا لا يعني صفر `bmc` عدم وجود تدريب فيه. أعدادها في تقرير الثالث وأدلته.
- `cache-files.json`: عدد موارد الكاش وأحجامها المحلية، مع احتساب الإدخالات المكررة كما هي معلنة.
- `tests.json`: نتيجة كل اختبار فاشل وسببه الأول. شُغلت ملفات `tests/*.cjs` منفردة بـNode؛ لم تُستخدم صيغة تمرر بقية الملفات كوسائط لأول اختبار فقط.
- `grade7-content-coverage.json`: حدود المقابلة البصرية للسابع. أدلة بقية الصفوف في المجلد الأعلى.

## إعادة الاختبار

تحتاج الأدوات Node وPlaywright ومتصفح Chromium محليًا؛ ليست تبعيات للموقع ولا تضيف مكتبات إلى صفحاته. يمكن تحديد مسار Playwright عبر `PLAYWRIGHT_MODULE` ومسار المتصفح عبر `BUSTAN_BROWSER`. الافتراضي هو حزمة `playwright` ومحركها المثبت. كان متصفح الجولة الأصلية Microsoft Edge على Windows.

من جذر المستودع:

```text
node reviews/evidence/new-grades/preview-server.cjs
node reviews/evidence/new-grades/browser-audit.cjs
node reviews/evidence/new-grades/weak-network-audit.cjs
node reviews/evidence/new-grades/question-display-audit.cjs
```

شغّل الخادم في جلسة طرفية مستقلة، وتأكد أن المنفذ `4199` متاح. النتائج الجديدة تُكتب في مجلد النظام المؤقت `bustan-new-grades-audit`، أو المسار الذي تختاره في `BUSTAN_AUDIT_OUT`؛ لا تُستبدل الأدلة المثبتة تلقائيًا. تُستخدم سياقات جديدة وملفات طلاب وهمية، وتُحاكى استجابات API محليًا. لا تختبر هذه الأدوات خادم Laravel أو حسابات الإنتاج.

تستخدم الجولة موقعًا تحت `/abboud-math/` لتطابق النشر في مسار فرعي. أغلق المتصفح الآلي والخادم بعد الانتهاء. ظهور صور غير محفوظة ورسائل انقطاع الشبكة في المرحلة المسماة offline نتيجة مسجلة، ولا يُصنف تلقائيًا خطأ JavaScript أثناء الاتصال.

# T31 — واجهة لوحة متابعة مستقلة

بتاريخ ١٧ تشرين الأول ٢٠٢٦ طلب محمد واجهة جديدة للوحة التحكم، وأكد أنه سيتولى ربطها بـ Laravel. بدأ الفرع `codex/dashboard-frontend` من آخر main عند `6d254b2` بعد سحبه. يتضمن هذا المرجع دمج الطلبات ٢٠–٢٦ ونسخ الكاش الجديدة وتصحيح اتجاه عينات الإنجليزية في الصفحة العامة.

## المنفذ

- مجلد `admin/` مستقل: نظرة عامة، الطلاب، تفاصيل الطالب، فهرس المواد الثماني، وحالة الربط.
- بحث عربي يتجاهل التشكيل، وتصفية بالصف والمادة، وتصدير CSV بوسم واضح للبيانات التجريبية.
- رسومات SVG محلية وخطوط وصور قائمة، وقائمة هاتف وتفاصيل قابلة للإغلاق بلوحة المفاتيح، ومراعاة تقليل الحركة.
- ملف بيانات مصطنع منفصل ودليل تسليم إلى Laravel. لا تحميل لـ profiles.js، ولا قراءة أو كتابة لتقدم الطالبين، ولا حفظ أو مصادقة أو مزامنة وهمية.
- عامل خدمة جديد بنطاق `admin/` يحفظ قائمة ملفات المعاينة العامة فقط، ويتجاوز API والطلبات خارج القائمة. لا تعديل لعامل الجذر أو عوامل المواد، ولا لـ catalog.js أو profiles.js.

إنجاز الدروس ونتيجة التدريب قيمتان منفصلتان في النموذج. لا يُسمّى اكتمال القراءة إتقانًا معرفيًا، ولا تُعرض نتيجة المعاينة بوصفها تقييمًا حقيقيًا للطالب.

## التحقق

نجحت ملفات `tests/*.cjs` الثلاثة والعشرون كلٌّ على حدة. يتضمن `tests/admin-dashboard.cjs` تشغيل الواجهة والعامل ببيانات مستقلة، والتحقق من اختلاف التدريب عن الإنجاز، وصحة روابط المواد، وتجاوز طلبات API، وعدم حذف كاش الجذر أو المواد، وعدم تخزين الاستجابات الفاشلة. لا يثبت الاختبار اسم إصدار كاش؛ يقارنه بمرجع Git عندما توجد نسخة سابقة.

فُحصت الأقسام الأربعة في Edge فعلي بعروض ٣٢٠ و٣٦٠ و٣٩٠ و٧٦٨ و١٣٦٦، ثم أُغلقت صفحة المعاينة وأُعيد فتحها دون شبكة داخل سياق الاختبار نفسه. نجح البحث والتصفية وتفاصيل الطالب والتصدير وقائمة الهاتف، ولم يظهر تجاوز أفقي أو أرقام لاتينية في النص المرئي أو أخطاء console. بقي مفتاح تخزين تجريبي دون تغيير، ولم تنشئ الواجهة مفاتيح أخرى. فُحص تفضيل تقليل الحركة كذلك. حُفظت صور ونتائج الاختبار محليًا خارج المستودع.

في تجربة منفصلة لأول زيارة على شبكة محاكاة بتأخير ٢٠٠ ملّي ثانية وتنزيل ٦٤ كيلوبايت في الثانية، جهزت الخطوط وكاش المعاينة خلال نحو ٤٫٧٣ ثانية، ثم نجحت إعادة الفتح دون شبكة. هذا قياس حالة اختبار محلية، وليس وعدًا بزمن موحد لكل جهاز أو شبكة.

أُعيد فحص المواد الثماني من النسخة المجمعة عند 6d254b2 على عرضي ٣٩٠ و١٣٦٦، ثم إعادة تحميل الصفحة الرئيسية لكل مادة دون شبكة: ثُبتت عوامل الخدمة وعملت الصفحات دون أخطاء console أو JavaScript أو تجاوز أفقي في الحالات المختبرة. كان تعليق المحاولة الأولى سببه خادم المعاينة المحلي الذي لم يخدم ترخيص الخط بامتداد txt؛ أُصلح الخادم خارج المستودع وأُعيد الفحص بنجاح، دون تغيير ملفات المواد.

## مراجعة قائمة الطلاب بعد ملاحظة محمد

استُبدلت بطاقات صفحة الطلاب بجدول قابل للبحث والتصفية والفرز بالاسم والصف، مع ١٠ أو ٢٥ أو ٥٠ صفًا في الصفحة. أُبقي التمرير الأفقي داخل الجدول على الهاتف، واختُصرت قائمة النظرة العامة إلى خمسة طلاب واقتراحين. يفتح كل صف تفاصيل الطالب عند الطلب. رُفعت نسخة كاش اللوحة.

نجح اختبار ١٣٧ طالبًا مصطنعًا: ١٤ صفحة عند عرض ١٠ صفوف، وسبعة صفوف في الصفحة الأخيرة، وحدود السابق والتالي، والعودة إلى الصفحة الأولى عند تغيير البحث أو الصف أو حجم الصفحة، وفرز الاتجاهين، وحماية أسماء الطلاب من تفسيرها بوصفها HTML. شُغّلت هذه الحالات في Edge على ٣٩٠ و١٣٦٦، ثم أُعيد فحص الحالات الأساسية على خمسة عروض ودون شبكة. لا يعني تقسيم المعاينة المحلي تنفيذ تقسيم خادمي؛ أوصى دليل التسليم بأن يعيد Laravel صفحة محددة من النتائج عند الربط.

## ما يلي عند الربط

هذه واجهة عامة تجريبية، وليست لوحة إنتاج مصادَقًا عليها. قبل تحويل HTML إلى Blade يحتوي بيانات خاصة، يجب إزالة سياسة كاش المعاينة وتنظيف نسخها السابقة، ثم تنفيذ المصادقة والصلاحيات وCSRF والتحقق الخادمي وحالات التحميل والخطأ. يشرح `admin/LARAVEL-HANDOFF.md` ذلك بالتفصيل. نقل التقدم إلى الخادم وحل تعارضاته مهمة مستقلة. تبقى D01 وD02 معلقتين دون تغيير.

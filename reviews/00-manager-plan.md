## طريقة الترتيب

الدرجة = أثر التعلّم × الخطورة ÷ الجهد. الأثر تقدير من ١ إلى ٥؛ الخطورة عالية = ٣، متوسطة = ٢، منخفضة = ١؛ الجهد صغير = ١، متوسط = ٢، كبير = ٣. هذه أوزان للتخطيط وليست قياسًا لتحسن الطالبين. استُبعدت المهام المدمجة من قائمة العمل. يمكن تنفيذ المتساوية بالتوازي إذا استقلت ملفاتها.

## شروط التنفيذ والتحقق

- سحب آخر main قبل بدء كل فرع؛ لا كتابة على main ولا force-push ولا دمج ذاتي. حُذفت الفروع القديمة بعد التحقق من دمجها دون حذف ملفات العمل.
- PR مستقل لكل مهمة، يذكر رقمها وسبب التغيير وكيف اختُبرت. تحديثات كاش المواد المشتركة تُدمج دون إسقاط عمل المساعد الآخر.
- قبل كل PR تُشغّل جميع ملفات tests/*.cjs، كل ملف بعملية Node. لا يثبت أي اختبار جديد اسم كاش معينًا؛ تُقارن نسخة العامل قبل التغيير وبعده.
- فحص متصفح فعلي للهاتف والكمبيوتر وconsole والعمل دون شبكة ببيانات اصطناعية مستقلة عن الطالبين.
- رفع نسخة كاش كل مادة متأثرة. لا تعديل لـ catalog.js أو profiles.js ضمن الدفعة. T29 يتطلب تعديل index.html وعامل الخدمة الجذري لكاش صفحة الزائر، ويُذكر ذلك صراحة في PR الخاص به.
- لا حذف للصور أو الأصوات أو مفاتيح التقدم، ولا ادعاء مطابقة كتاب أو اعتماد صوت لم يُراجع فعلًا.

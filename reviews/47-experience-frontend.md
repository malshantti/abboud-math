# مراجعة الواجهات والأداء — الصفوف ٣ و٤ و٥ و٧

الأساس: main عند `95a059b3`، بتاريخ ٢ نوفمبر ٢٠٢٦. قراءة وفحص فقط؛ لا إصلاحات في هذا الفرع. فُحصت المواد الست عشرة، وليست نسخة الاستضافة. حسابات اصطناعية وAPI محاكى؛ لا تحقق من Laravel أو مزامنة الطلاب الحقيقية.

٣٥٢ حالة عرض: لكل مادة الرحلة، أول وآخر درس، الأساسيات، المغامرات وأول نشاط، المختبر وأول نشاط، التقرير، ثم الصفحات الرئيسية الخمس بعرض ٣٢٠ و١٣٦٦ بكسل، وإعادة التحميل دون شبكة. العرض الأساسي ٣٩٠ بكسل. ليست هذه تغطية لكل سؤال وكل مختبر. لا أخطاء JavaScript أو console أثناء الاتصال أو استجابات ملفات فاشلة في العينة. نجحت الاختبارات الـ٧٤.

عينة شبكة ضعيفة لعلوم السابع: تأخير ٤٠٠ ملي ثانية، تنزيل ٦٤ كبيبايت/ثانية، رفع ٣٢ كبيبايت/ثانية؛ الصفحة الرئيسية والخطوط نحو ١٣٫٥٦ ثانية. هذه قياسات محلية مفردة لا تمثل أداء الإنتاج ولا متوسطًا إحصائيًا. زر تنزيل الكتاب موجود. إعادة فتح النص دون شبكة نجحت؛ ظهرت صور غير مخزنة في آخر درس في ١١ مادة لأن الاختبار لم ينزّل الكتاب كاملًا ولم يمرر كل صوره الكسولة. لا تُسجل كفشل تنزيل الكتاب؛ اختبار اكتمال تنزيل كل كتاب خارج نطاق هذه الجولة.

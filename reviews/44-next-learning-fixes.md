## تحقق N16

أُزيل الخيار الرابع الفارغ وحده من g7/math/content.js، U5L1.bmc[4]. الخيارات الباقية «حاصرتين { }» و«قوسين ( )» و«عارضتين»، والمفتاح ما زال الأول. الإحالة الداخلية ١٠٠٦ محفوظة ويعرضها منسق الكتاب ص٦ ج٢. لم يُغيّر معرّف درس أو مفتاح تقدم أو تسجيل صوتي.

نجح اختبار بنيوي لـ٤٦٩٢ سؤالًا عبر ١٢ مادة في الرابع والخامس والسابع: بديلان على الأقل، مفتاح صالح، وكل بديل نص غير فارغ. نجاح البنية لا يثبت صحة المحتوى العلمي كله.

نجحت ملفات الاختبار الـ٧٢ في n16-all-tests-final.log. فُتح السؤال الفعلي بعرض ٣٩٠ و١٣٦٦، أثناء الاتصال وبعد إعادة التحميل بلا شبكة. ظهرت ثلاثة أزرار ذات نص وقُبلت «حاصرتين { }» في الحالات الأربع، دون أخطاء console أو JavaScript أو تجاوز أفقي. البيانات اصطناعية في سياق مستقل؛ الأدلة خارج المستودع: D:/موقع زيتون/tools/n16-choice-browser/results.json ولقطاته. رُفع إصدار كاش رياضيات السابع دون تثبيت اسم إصدار في الاختبار.

## ما يبقى خارج هذه الدفعة

بقية ملاحظات التقارير ٣٨–٤١، ومنها نماذج الجمل الإنجليزية ومطابقة المختبرات للمستوى وتوصيف الجزأين والأخطاء اللغوية، تبقى مفتوحة حتى إصلاحها والتحقق منها. تسجيلات لهجاتي الناقصة مؤجلة لتوريد محمد، والمطابقة الحرفية الشاملة تحتاج تحديد الطبعة المرجعية. لا تعني هذه الدفعة اعتمادًا وزاريًا أو اكتمال المنهاج.
